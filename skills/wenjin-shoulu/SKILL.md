# 问津收录

这是问津的显式收录入口。找到同一技能目录中的 `wenjin/SKILL.md`；若安装位置不同，从当前可用技能列表定位 `wenjin`。按其中的“收录与维护”规则处理用户提供的链接，写入 `~/.wenjin/catalog.md`。缺少链接时，请用户提供要收录的来源；一个仓库有多件 Skill 时，先确定具体条目。

收录只保存来源和摘要，保持“候选”“未分类”状态，不安装或执行外部 Skill。完成后说明实际写入的目录位置；不要把本地写入说成已经同步到 GitHub。
