# 问津收录

这是问津的显式收录入口。找到同一技能目录中的 `wenjin/SKILL.md`；若安装位置不同，从当前可用技能列表定位 `wenjin`。先按问津规则运行首次配置脚本，再按“收录与维护”规则处理用户提供的链接，写入 `~/.wenjin/catalog.md`。缺少链接时，请用户提供要收录的来源；一个仓库有多件 Skill 时，先确定具体条目。

收录只保存来源和摘要，保持“候选”“未分类”状态，不安装或执行外部 Skill。写入后运行相邻 `wenjin` 技能目录中的 `scripts/sync_catalog.py`，将个人目录自动同步到已配置的 GitHub 私有仓库。同步成功时说明实际写入位置和仓库；失败时说明条目已留在本地、未同步，并给出脚本返回的原因，不要声称已同步。
