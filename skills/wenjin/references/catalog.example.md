# 问津目录

这里是问津个人目录的空白模板。实际目录保存在 `~/.wenjin/catalog.md`，不进入主体代码仓库。
收录一项时，在本文件末尾新增一个二级标题。标题使用稳定、简短的名称；字段按下列模板填写。来源尽量指向具体文件，并记录固定提交版本。一个仓库含多个 Skill 时，每件分别建卡。
